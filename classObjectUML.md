## **Class Description**
### My class represents what the user wants to add to the list which includes; name of character, which nation they're from, and what element they use, what weapon they use.
---
## **Properties**
| Property | Data Type | Description |
|---|---|---|
| Name | string | Name of the character. |
| Nation/Area | string | The place where the character is from ( Monstadt, Liyue, Inazuma, Sumeru, Fonatine, Natlan, Nod - Krai, and Snezhnaya ).  |
| Elemental Vision | string | The element that the character uses ( Anemo, Geo, Electro, Dendro, Hydro, Pyro, and Cryo ). |
| Weapon | string | The weapon the character uses ( Sword, Claymore, Catalyst, Polearm, and Bow  |
