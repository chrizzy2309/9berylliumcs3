# ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

### 1. Encapsulation
Encapsulation protects product details, such as stock and price, by combining them inside a single object and restricting direct external access. It forces all inventory changes to go through designated functions that validate inputs preventing errors like negative counts. This ensures the stores inventory records are accurate.

### 2. Abstraction
Abstraction hides all the complicated code so the user only sees simple actions. People just tap the buttons not worrying about how it works. This makes the system easy to use and easy to fix.

### 3. Inheritance
Inheritance lets special items reuse basic information from an existing product. The special item only adds important details like expiration date instead of starting from new information. This saves time and stops programmers to start from scratch every time.

### 4. Polymorphism
Polymorphism allows different types of products to  react to the same command on their own way. For example a standard product shows its normal price while a special product like perishable food near its expiration automatically has a discount . This lets the system handle a mix of different items without getting confused.
